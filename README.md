## 👋 About me

I'm a full-stack software engineer at **[Arbisoft](https://arbisoft.com)** in Lahore, Pakistan, building products there since 2021. I work across the whole stack: Python/Django services and background jobs, React and TypeScript web apps, and native macOS apps in SwiftUI. I like owning a feature end to end, from the data model and API to the UI and the tests that keep it working.

- 🎓 BS Computer Science, University of the Punjab
- 💬 Happy to talk about Django + Celery, Google Workspace APIs, Stripe billing and SwiftUI
- 📫 The fastest way to reach me is [email](mailto:goharattiq@hotmail.com) or [LinkedIn](https://www.linkedin.com/in/gohar-attiq-42b627197)

## 🚀 What I'm working on

I'm a full-stack engineer on an **AI meeting-notes platform**. A note-taker bot joins Google Meet and Zoom calls, and the product turns each recording into a transcript, a summary and action items. I work on every part of it:

| | Area | What I work on |
|:-:|---|---|
| ⚙️ | **Backend**<br><sub>Django · DRF · Celery · PostgreSQL · Redis</sub> | The meeting bots and their Celery pipelines, context for recurring meetings, action items that become Google Tasks with due dates and completion kept in sync, and Stripe + Lago billing with feature access per plan and per user |
| 🌐 | **Web app**<br><sub>React 18 · Redux Toolkit</sub> | Home, meetings, follow-ups and recurring-meeting screens |
| 🍎 | **macOS app**<br><sub>SwiftUI · AppKit · SwiftData</sub> | On the native desktop client: tasks, collections, follow-ups, a shared design system and accessibility fixes |
| 🛠️ | **Admin console**<br><sub>Vite · TypeScript · Tailwind · Radix</sub> | The internal dashboard for users, meetings, organizations and usage |
| 🤖 | **AI-assisted engineering**<br><sub>Claude Code</sub> | Hooks and guardrails the team uses every day: secret blocking, protected-branch pushes and auto-formatting |
